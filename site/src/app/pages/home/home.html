About Sand3

Sand3 is an open-source, high-performance cellular automaton sandbox engine designed for experimenting with complex particle dynamics, physical reactions, and cellular life. Every material in the simulation can be created, styled, and given arbitrary reaction rules evaluated on a custom grid neighborhood.

GPU or CPU simulation Hardware-accelerated Vulkan compute shaders or multithreaded CPU processing.
Customizable Grid Size Dynamic canvas sizes from 128×128 up to 4096×4096 with presets and content preservation.
Up to 255 Materials Full RGB colors, inheritance hierarchies, and completely customizable rules.
Customizable Neighborhood Rules Defines complex emergent behaviors, rotational symmetries, and probabilities.
Selection & Transform Move, copy, cut, paste, resize, flip, and rotate rectangular regions with transparency.
Creative Tool Suite Square/Circle brushes, straight lines, flood fill, stamps, and undo/redo history.
Compressed Storage Lossless BWT + RLE compression algorithm for efficient .save and .stamp files.
Integrated Workshop One-click downloading, automatic set dependency resolving, and community item sharing.

Simulation Architecture & Rules

Sand3 uses a completely customizable neighborhood for your rules! This allows for some extremely complex behaviours. By default it uses a 3x3 neighborhood but you can increase it up to 10x10 if you want (or even higher).

WHEN Grid ➔ THEN Grid

Rules can match multiple possible materials per cell, specify execution chances, and apply horizontal flip, vertical flip, or 90° rotation symmetries automatically.

Materials can also inherit basic rules from parent materials (e.g. all liquids inheriting standard gravity flow, with custom rules added on top).

Continuous Attributes & Equations

Sand3 supports up to 3 continuous physical attributes (e.g. Temperature, Pressure). Reaction rules can dynamically calculate new attribute values with an intuitive mathematical equation workflow:

  • Click-to-Add Cell References: With the THEN cell popup open, click any cell in either the WHEN or THEN grid to append its position badge (e.g. [0, 1]) into the equation.
  • Uneditable Badges & Relative Mode: Cell references appear as uneditable badges directly inside the equation text. Badges default to absolute positions that remain fixed when copying cells. Right-click any badge directly inside the box to toggle it into relative mode (~[dx, dy]), which shifts dynamically with cell copy offsets. Shift-click to remove.
  • Direct Keyboard Input: Click the equation box to type mathematical operators and expressions (+, -, *, /, ( ), min(), max(), clamp(), abs()) directly on your keyboard.

Building from Source

Requires a C++20 compiler and CMake 3.25+. All major third-party dependencies (SDL3, ImGui, Volk, fmt, nlohmann_json, miniz, libcurl) are bundled as submodules or static libraries.

Clone with all submodules: 

git clone --recursive https://github.com/cast-e/Sand3.git
cd Sand3

If you already cloned without --recursive, fetch submodules manually: 

git submodule update --init --recursive

Linux Prerequisites

Install GCC 12+ (or Clang 16+), CMake 3.25+, and Ninja: 

# Debian/Ubuntu based
sudo apt install build-essential cmake ninja-build git
# Arch-based
sudo pacman -S base-devel cmake ninja git

Building on Linux (GCC)

Release build (recommended) 

cmake --preset linux-gcc
cmake --build --preset linux-gcc

Debug build 

cmake --preset linux-gcc-debug
cmake --build --preset linux-gcc-debug

Running on Linux

cd ./bin/linux
./sand3

Cross-compilation to Windows (MinGW-w64)

Requires mingw-w64 installed on your Linux host: 

cmake --preset windows-mingw
cmake --build --preset windows-mingw

Windows Prerequisites

Install MinGW-w64 (GCC 12+) and Ninja, recommended via MSYS2 UCRT64: 

pacman -S mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-ninja

Ensure C:\msys64\ucrt64\bin is added to your system PATH.

Building on Windows (MinGW-w64 + Ninja)

Release build (recommended) 

cmake --preset windows-mingw
cmake --build --preset windows-mingw

Debug build 

cmake --preset windows-mingw-debug
cmake --build --preset windows-mingw-debug

Running on Windows

Produces a clean standalone executable: 

cd .\bin\win64
.\sand3.exe
