About Sand3

Sand3 is an open-source, high-performance cellular automaton sandbox engine designed for experimenting with complex particle dynamics, physical reactions, and cellular life. Every material in the simulation can be created, styled, and given arbitrary reaction rules evaluated on a 5x5 grid neighborhood.

GPU or CPU simulation Hardware-accelerated Vulkan compute shaders or multithreaded CPU processing.
Up to 255 Materials Full RGB colors, inheritance hierarchies, and completely customizable rules.
5x5 Neighborhood Rules Defines complex emergent behaviors, rotational symmetries, and probabilities.
Creative Tool Suite Square/Circle brushes, straight lines, flood fill, stamps, and undo/redo history.
Compressed Storage Lossless BWT + RLE compression algorithm for efficient .save and .stamp files.
Integrated Workshop One-click downloading, automatic set resolution, and community item sharing.

Sand3 runs as a standalone binary with zero external runtime package dependencies. Requires a Vulkan-capable GPU driver (Mesa, NVIDIA, or AMD).

Simulation Architecture & Rules

Unlike traditional 3x3 Moore-neighborhood cellular automata, Sand3 utilizes a full 5x5 neighborhood matrix centered on each cell. This allows modeling momentum, fluid dispersion, cellular growth, gas diffusion, and mechanical collision:

WHEN Grid (5x5) ➔ THEN Grid (5x5)

Rules can match multiple possible materials per neighbor cell, specify execution chances (probabilities), and apply horizontal flip, vertical flip, or 90° rotation symmetries automatically.

Materials can inherit base rules from parent materials (e.g. all liquids inheriting standard gravity flow, with custom rules added on top).

Building from Source

Requires a C++20 compiler (GCC 12+ or Clang 16+) and CMake 3.25+. All third-party dependencies (SDL3, ImGui, Volk, fmt, JSON) are bundled in the repository. 

# Clone repository with all submodules
git clone --recursive https://github.com/cast-e/Sand3.git
cd Sand3

# Build on Linux (Release)
cmake -B build --preset linux-gcc
cmake --build build

# Cross-compile for Windows with MinGW-w64
cmake -B build --preset windows-mingw
cmake --build build
